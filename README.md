# Proyecto Bibliorama

La <b>biblioteca</b> es un centro de conservación de libros desde las epocas más antiguas hasta la actualidad. No obstante, este lugar es un enfoque de mejora continua y modernización, o bien decir, la digitalización. He desarrollado esta aplicación de <b>planificación de recursos empresariales </b> o <b>ERP</b> con tecnologías (framework) de <b>.NET</b>, <b>C#</b>, y con una <b>arquitectura por capas</b> conocida también como <b>Clean Architecture</b>. Se trata de control eficiente de inventario de libros, préstamos, devoluciones y reservas, así como la gestión de usuarios y membresías.
